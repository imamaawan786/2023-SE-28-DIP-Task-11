# 2023-SE-28-DIP-Task-11
Task 11
Create a Python script suitable for Google Colab that performs morphological image processing on a user-uploaded image. The script should:
Allow the user to upload a grayscale or binary image interactively.
Convert the image to binary if it’s not already in binary format.
Apply basic morphological operations such as erosion, dilation, opening, closing, as well as boundary extraction, hole filling using morphological reconstruction, and noise removal.
Detect shapes by finding contours, approximating polygonal curves, classifying shapes as triangles, rectangles, or circles, and labeling them on the image.
Display all the results in a single figure with multiple subplots using Matplotlib, including the original binary image, erosion, dilation, opening, closing, boundary extraction, hole filling, noise removal, and shape detection.
